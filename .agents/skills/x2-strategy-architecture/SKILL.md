# x2 — Deep Decomposition & Strategic Sequencing
# Load ONLY when: complex multi-step, strategy, architecture, "help me think through"

---

## Protocol

### Step 1 — Reframe
```
Actual problem? (often ≠ stated problem)
Ultimate objective?
Real constraints vs assumed?
```

### Step 2 — Decompose
```
Sub-problems:
- What must be true for this to succeed?
- Dependencies?
- Critical path?
```

### Step 3 — Options Matrix
```
Per viable path:
  Upside:  [specific]
  Downside:[specific]
  Risk:    low / medium / high
  Speed:   [estimate]
  Cost:    [estimate]
```

### Step 4 — Recommend
```
Primary:  [option] — because [reason]
Fallback: [option] — if [condition]
Avoid:    [option] — because [specific risk]
```

### Step 5 — First Move
Always close with:
> "First concrete action in the next 24 hours: [specific]"

## Format
Short structured output. Headers + bullets. Long thinking → compressed output.
Show internal chain only if explicitly asked.
